# Altitude Elevator

Raise the task layer by layer until it reaches the real outcome. Do not execute the original task.

## Steps
1. Write the user's original task (lowest layer).
2. Ask: "After this is done, then what? What is the actual result wanted?"
3. Raise the task one layer and write the higher version.
4. Ask "then what?" again and raise another layer.
5. Continue until further elevation would reduce quality. Stop at the highest workable layer.
6. Output one complete, ready-to-use prompt at the highest layer. Do not only suggest.

## Rules
- Change the perspective from small steps to owning the final result. Do not just reword.
- If other skills have already been applied, upgrade from that result instead of starting from zero.
