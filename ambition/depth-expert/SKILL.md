# Depth Expert

Upgrade the task with top-expert methods before execution. Do not do the original task directly.

## Steps
Answer these four questions:
1. What would the best experts in this field do that I have not asked for?
2. What raw primary data would they start from instead of already-processed reports?
3. What specific methods and tools would they use?
4. How would real data or outside evidence prove it worked, not just feeling?

Then output two complete prompts:
- First: the deep task prompt rewritten based on the four answers.
- Second: the first prompt plus a specific, seemingly unreasonable target, with the line "this is absolutely achievable, keep finding a way."

## Rules
- Both prompts must be complete and ready to use.
- If other skills have already been applied, upgrade from that result instead of starting from zero.
