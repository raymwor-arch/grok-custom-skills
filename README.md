# Grok Custom Skills

Custom skills synced from local Grok environment.

Sorted and categorized by function / purpose.

## Categories

### Debugging
- **diagnosing-bugs**: Diagnosis loop for hard bugs and performance regressions.

### Domain Modeling
- **domain-modeling**: Build and sharpen a project's domain model (CONTEXT.md, ADRs).

### Grilling / Stress-testing
- **grill-me**: Relentless interview to sharpen a plan or design (stateless).
- **grill-with-docs**: Grilling plus docs (ADRs and glossary).
- **grilling**: General grill the user relentlessly about a plan/decision.

### Collaboration / Communication
- **handoff**: Compact conversation into a handoff document for another agent.
- **wait-what**: Stop and re-pitch the last message that did not land.

### Research
- **research**: Investigate a question against high-trust primary sources.

### Teaching
- **teach**: Teach the user a new skill or concept.

### Decision Making
- **to-questionnaire**: Turn a decision into a questionnaire for someone else.

### Agent Writing
- **writing-for-agents**: Writing documents for agents (skills, AGENTS.md, CLAUDE.md).

---

Each skill lives in `category/skill-name/` with its SKILL.md and supporting files.
